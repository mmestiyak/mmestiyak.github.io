A lightweight npm package that converts any 3D model (GLB, GLTF, OBJ, FBX) into a sprite strip for performance-friendly browser previews. Captures 18 frames of a 360° rotation and stitches them into a single image — eliminating the need for heavy WebGL rendering. Includes React hooks API and SpriteStripViewer component.
